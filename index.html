PDF Library & Reader

The Reading Room

2026.05.11 – 05.17개인 · 바이브코딩데모 보기

개요

PDF 문서를 업로드해 나만의 서재처럼 정리하고, 브라우저 안에서 바로 읽을 수 있는 PDF 라이브러리 & 리더 웹 애플리케이션. 계정으로 로그인하면 책이 클라우드에 저장·동기화되어 어느 기기에서나 같은 서재를 이어서 볼 수 있다.

  • 프로젝트 유형1인 개발 (개인 프로젝트)
  • 제작 방식AI 페어코딩(바이브코딩)으로 빠르게 프로토타이핑하며 디자인·기능을 반복 개선
  • 동기어떤 기기에 있는 PDF 파일을 휴대폰·패드 등 다른 기기에서도 볼 수 있으면 시간·장소에 구애받지 않고 PDF를 조회할 수 있어 유용할 것이라 생각

목표

서버를 직접 구축·운영하지 않고도 인증 · 저장 · 동기화가 매끄럽게 이어지는, 실제로 쓸 수 있는 클라우드 PDF 서재를 만드는 것. 외부 PDF 렌더링 엔진과 BaaS를 조합하고, 다량의 PDF에서도 끊김 없는 읽기 경험을 위한 성능 최적화를 직접 구현하는 것.

기술 스택

  • 언어: HTML · CSS · JavaScript (Vanilla, 프레임워크 미사용)
  • PDF 렌더링: pdf.js (Mozilla)
  • 백엔드/인증: Supabase (Auth · Database · Storage)
  • 로컬 캐시: IndexedDB
  • 성능: IntersectionObserver 기반 지연 렌더링, 동시성 제어
  • 제작: 바이브코딩 (AI 페어 프로그래밍)

핵심 기능

  • PDF 업로드 & 서재
    • 드래그 앤 드롭 또는 파일 선택으로 PDF 추가
    • 첫 페이지를 자동으로 썸네일 생성해 책장(그리드) 형태로 표시
  • 폴더 & 검색
    • 폴더(컬렉션)를 만들어 책을 분류하고 필터바로 빠르게 전환
    • 제목 기준 실시간 검색
  • 인앱 PDF 리더
    • 페이지 연속 스크롤로 읽기, 페이지 인디케이터 및 썸네일 네비게이션
    • 화면에 들어오는 페이지만 렌더링하는 지연 로딩
  • 로그인 & 클라우드 서재
    • 이메일/비밀번호(이메일 인증 포함) 및 Google 로그인
    • 로그인 후 책 메타데이터와 파일을 클라우드에 저장해 기기 간 동기화
  • 데이터 마이그레이션기존 로컬(IndexedDB)에 저장돼 있던 책을 감지하면 클라우드로 한 번에 옮겨주는 마이그레이션 배너 제공
  • 관리 기능책 이름 변경·삭제, 저장 용량 배지 및 라이브러리 통계 표시

핵심 구현 포인트

  • 클라우드 저장 + 로컬 캐시책은 Supabase Storage/DB에 저장하고 IndexedDB를 PDF 바이트·썸네일 캐시로 활용해 재방문 시 로딩 비용을 줄이는 데이터 흐름 설계
  • 인증 상태 콜백 데드락 회피onAuthStateChange 콜백 안에서 DB/Storage 호출을 그대로 await하면 후속 인증 이벤트(로그아웃 등)가 막히는 문제를 setTimeout으로 defer해 해결
  • 썸네일 동시성 제어썸네일을 한 번에 2개씩만 렌더링하도록 제한(throttle)해 PDF가 많아도 UI가 멈추지 않도록 최적화
  • 지연 렌더링IntersectionObserver로 뷰포트에 들어온 페이지만 렌더해 메모리·성능 부담 최소화
  • 실서비스 수준 인증 흐름이메일 인증/재전송, Google OAuth, Supabase 에러 메시지 파싱까지 구현
  • 일관된 디자인 시스템동일 계열 플래너 프로젝트와 같은 Apple 스타일 디자인 토큰(CSS 변수)을 공유해 통일된 비주얼 유지

Review

바이브코딩으로 pdf.js 같은 외부 렌더링 엔진과 Supabase 같은 BaaS를 조합해, 인증부터 저장·동기화·렌더링까지 이어지는 풀스택에 가까운 앱을 직접 완성해볼 수 있었다. 클라우드 저장과 로컬 캐시를 함께 다루는 데이터 흐름을 고민하고 구현 과정에서 발생한 실제 문제를 해결하며, 다량의 문서에서 지연 렌더링·동시성 제어 같은 성능 최적화가 왜 필요한지 체감했다. 또한 백엔드(Supabase)는 AI가 다룰 수 없는 영역이라 직접 구현했는데, 이 과정에서 백엔드의 대략적 구현 과정과 개념을 생각해볼 수 있었다.
